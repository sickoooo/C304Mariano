## 🚀 Features
* **Roman Aesthetic UI:** Custom Gold (`#c8a45c`) & Papyrus theme.
* **Day/Night Toggle:** Persistent Light and Dark mode switching using LocalStorage.
* **Interactive Animations:** Custom JavaScript canvas background (Squares) and SVG text marquees.
* **Achievements Hall:** Showcase for Cisco Certificates & MLBB Tournament wins ⚔️.
* **Personal Gallery:** A special section dedicated to my 19 pets 🐾.
* **Contact System:** Functional contact form layout.
